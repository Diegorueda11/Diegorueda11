## 🚀 About Me

I'm a **Systems Engineer** graduated from the **Universidad Autónoma de Bucaramanga (UNAB)**, working as an **integration and full-stack developer** at **E3 CreaTIC**.
I build backend services, integrations and web applications for **IT operations** in the telecommunications sector.

- 🧠 **AIOps**: full-stack development of a monitoring and incident management platform (Python + React)
- 🔗 **System integrations**: middleware that keeps an ITSM platform in sync with external systems
- 📞 **Operations portals**: web apps to query and manage incidents, with SSO and role-based access
- 🗄️ **Data**: SQL schema design, migrations and performance improvements
- 🤖 **Automation**: rule engines, workflows and bots that reduce manual work
- 🧠 Working daily with **AI-assisted development** and multi-agent workflows

## 🛠️ How I Work

- **Sandbox → release → archive**: every change is tested in TEST before it reaches production, with a rollback point always available
- **Idempotent by design**: locks, unique constraints and retries so concurrent calls don't create duplicate tickets
- **Documented**: changelogs, technical docs and flow diagrams for each integration
- **Privacy first**: customer data stays out of logs and ticket comments
- **Contract-first APIs**: OpenAPI as the source of truth, with generated frontend types and tests on both sides
- **Measured, not assumed**: every fix records what was verified and what wasn't
